SYSTEMS / C++ Fundamentals

RAII, Move Semantics & The Rule of Five

In modern C++, managing dynamic heap memory deterministically without garbage collection overhead requires strict adherence to Resource Acquisition Is Initialization (RAII). Implementing move constructors transfers ownership via pointer stealing without deep copies.

class Buffer {
    size_t sz;
    int* data;
public:
    // Move constructor: steal pointer, nullify source
    Buffer(Buffer&& o) noexcept 
      : sz(o.sz), data(o.data) {
        o.data = nullptr;
        o.sz = 0;
    }
};
Key Takeaway: Move semantics turn expensive \(O(N)\) heap copy operations into \(O(1)\) pointer swaps, making value semantics performant in high-throughput systems.
SYSTEMS / HARDWARE Performance

Cache Locality & Memory Layout

Theoretical time complexity \(O(N)\) can be misleading without understanding CPU cache line hierarchies. Contiguous flat arrays trigger hardware prefetching into L1/L2 caches, outperforming linked node pointers by orders of magnitude.

// Row-Major: Contiguous cache line hits
for (int r = 0; r < N; ++r)
  for (int c = 0; c < N; ++c)
    sum += matrix[r][c]; // 64-byte spatial prefetch
Key Takeaway: Spatial locality matters as much as algorithmic complexity. Traversing memory sequentially avoids expensive CPU pipeline stalls and RAM latency penalties.
AI / TRANSFORMERS Architecture

Anatomy of Scaled Dot-Product Attention

Transformers replace sequential recurrence with self-attention by mapping inputs to Query (\(Q\)), Key (\(K\)), and Value (\(V\)) matrices. Dotting \(Q\) with \(K^T\) computes pairwise token affinity, scaled by \(\sqrt{d_k}\) to prevent vanishing softmax gradients.

# Scaled Dot-Product Attention
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
attn_weights = torch.softmax(scores, dim=-1)
output = torch.matmul(attn_weights, V)
Key Takeaway: Scaling by \(\frac{1}{\sqrt{d_k}}\) ensures matrix dot products in high dimensions do not push softmax into regions with near-zero gradients.
AI / SYSTEMS RAG & Search

Dense Embeddings vs. Lexical BM25 Search

In Retrieval-Augmented Generation (RAG), pure vector similarity can miss exact serial numbers, error codes, and entity names. Hybrid search combines dense semantic embeddings with sparse BM25 keyword matching for optimal recall.

# Reciprocal Rank Fusion (RRF)
def rrf_score(rank_dense, rank_bm25, k=60):
    return (1.0 / (k + rank_dense)) + (1.0 / (k + rank_bm25))
Key Takeaway: Hybrid retrieval bridges conceptual reasoning (dense embeddings) with exact lexical precision (sparse BM25), eliminating hallucination vectors.
